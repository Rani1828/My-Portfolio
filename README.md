# 🌐 Rani — Personal Portfolio

A modern personal portfolio website created to showcase **Rani's** profile, skills, services, projects, and professional work. ✨

The website combines a clean portfolio layout with interactive project experiences and practical features for connecting with visitors.

## ✨ Features

🎨 **Modern Portfolio UI** — A polished red-themed interface with clear navigation and visually organized sections.

📄 **CV Download** — Visitors can download Rani's CV directly from the Contact section.

💼 **Project Showcase** — Displays featured work, including a music player project and other development projects.

📩 **Real Contact Form** — Visitors can submit their name, email, and message through the form. The submitted information is collected **in real time in Google Sheets**, making it a genuine data-collection feature rather than a dummy form.

## 🖥️ Website Sections

🏠 **Home** — Professional introduction and web-developer profile.

👤 **About Me** — Personal introduction, skills, experience, and education information.

🛠️ **Services** — Highlights Web Designing, UI/UX Designing, and App Development services.

💼 **Portfolio** — Showcases projects with dedicated project experiences, including the **ECLIPSE music player** built with HTML, CSS, and JavaScript.

📩 **Contact Me** — Contact details, social links, CV download, and the functional Google Sheets-connected contact form.

## 📱 Responsive Design

The website uses a structured, user-friendly layout with organized navigation and section-based content. The provided demonstration primarily shows the desktop interface.

## 🛠️ Technologies Used

💻 HTML5 • 🎨 CSS3 • ⚡ JavaScript  
📊 Google Sheets integration for real-time contact-form data collection

## 🎯 Project Purpose

This project demonstrates practical front-end development through a professional portfolio that combines **personal branding, service presentation, project showcasing, CV access, and real-time contact-data collection**. 🚀
